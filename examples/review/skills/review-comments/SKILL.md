# Review comments

Write each inline comment for the author, who reads it next to the line.

- Say what is wrong in the first sentence, then why it matters.
- Suggest a fix when you know one, as a short code block or a `suggestion` block.
- Comment on the line that causes the problem, not on the line where it shows.
- Leave out praise, style the formatter decides, and anything the checks already report.
- Mark a comment that blocks the merge with `Blocking:` at its start. Leave the others unmarked.
